# GDBLE v0.6.0

## 新增

- 增加统一 `ble_event` 事件协议，使用 operation ID 关联请求和终止结果，并提供稳定错误码与完整 GATT 上下文。
- 后台 BLE Core 统一管理运行时、扫描、设备串行队列和通知流；Godot 对象保留主线程 API 与缓存。
- Android 使用 Godot v2 插件和独立的 GDBLE、btleplug 两个 AAR，支持 ARM64 与 x86_64。

## 修复与改进

- 修复设备回调重入 Manager 的借用冲突，以及主动断连的系统回声取消后续重连的问题；用连接代际和后端查询核验迟到事件。
- 补齐四类广播属性更新、适配器可用性和服务变化；属性快照读取独立执行并有超时。
- 订阅前准备唯一通知接收器；订阅期间限额暂存，通知溢出显式失败、停止通知并保留连接，重新订阅重建接收流程。
- 请求接纳前预留可靠事件容量，控制循环不再等待外发事件队列；控制和高频数据分别限容。
- 两份 Demo 共享 Android 权限启动器，确认全部授权才初始化，前后台切换不循环弹窗。
- 增加内嵌构建信息、源码摘要和最终 addon 冒烟门禁；发布提交可用源码摘要关联构建提交，测试接口不会进入发行库。
- 修复事件队列满时本地失败通知丢失，以及命令队列满时停止扫描请求丢失的问题。
- 修复失败或取消请求导致连接状态错误、非终止扫描错误被当成扫描结束，以及事件回调读取到旧缓存的问题。
- 为后台操作增加超时与异常处理，为关闭流程设置时间上限。
- 处理适配器和通知流意外结束，并拒绝旧会话的迟到通知和错误。
- 修复全新 checkout 中 Godot 冒烟测试无法识别扩展类的问题，统一 CI 与预发布的 AAR 校验。
- 升级 `async-trait`，修复 Rust 1.99 下宏生成的重复 `must_use` 标记导致严格 Clippy 检查失败的问题。
- 构建脚本在原生命令失败时立即退出，避免复制历史产物；GitHub Release 正文从版本化 Markdown 文件读取。

## 升级说明

- 保留 0.5.x 类名、方法参数与旧信号。异步方法返回的 operation ID 可以忽略。
- 参数错误和命令队列拒绝会在发起调用的对象上同步发出失败事件；请在调用前连接信号。已接纳操作仍异步完成。
- `connect_device()` 是设备对象工厂；实际连接需要调用 `BleDevice.connect_async()`。
- 完整复制 `addons/gdble` 安装；Android 需要同时包含两个 AAR，并由应用申请运行时蓝牙权限。

## 已知限制

- 最低 Godot 版本为 4.2；不支持 iOS、Android ARMv7 和自动重连。
- 适配器事件流结束后需要重新调用 `initialize()`；通知流结束后需要重新订阅以恢复通知。
- 跨服务订阅同一个 characteristic UUID 会返回 `AMBIGUOUS_CHARACTERISTIC`。
- Android API 23–30 与 API 31+ 真机 BLE 闭环仍是发行验收条件；模拟授权测试、AAR 结构校验不能替代设备证据。
